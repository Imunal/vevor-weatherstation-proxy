# VEVOR Weather Station Proxy

A lightweight weather station proxy written in Rust using Axum.

This project provides a proof of concept for intercepting weather data sent by VEVOR weather stations to cloud services such as Weather Underground and Weathercloud.

The proxy receives the original HTTP requests generated by the weather station, parses and normalizes the measurements, and persists them locally for analytics and further processing.

After the data has been successfully persisted, the proxy immediately responds to the weather station with `200 OK`. Delivery to external weather services is handled asynchronously through an outbox, so temporary cloud service failures do not interrupt local data collection.

## Data Flow

VEVOR Weather Station
→ Proxy / Axum
→ Parse & Normalize
→ Persist locally
→ `200 OK` to the weather station
→ Outbox
→ Weather Underground / Weathercloud

The goal is to provide full ownership of weather station data while preserving compatibility with the cloud services supported by the original VEVOR firmware.

The project is currently a proof of concept and is under active development.

For this example, i'm using VEVOR YT60234
